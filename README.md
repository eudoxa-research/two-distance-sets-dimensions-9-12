# Maximum two-distance sets in Euclidean spaces of dimension nine, ten, eleven and twelve

**Bryan Zachary Bu, Karam Gill, Hyunjun Yi**

September 2026.

DOI: [10.5281/zenodo.23343351](https://doi.org/10.5281/zenodo.23343351)

## Abstract

We prove g(9) = 45, open since Lisoněk’s 1997 work left 45 ≤ g(9) ≤ 55, and show that up to similarity there are exactly two 45-point two-distance sets in ℝ⁹. We also prove g(10) = 55, g(11) = 66 and g(12) = 78, each attained only by the simplex-midpoint set. The method is a root-lattice reduction plus a symmetry-reduced exhaustive search, cross-checked by an independent SAT-based implementation.
